# Student Performance Prediction

B.Tech S3 AI & Data Science project using K-Means Clustering and Random Forest.

## Run
```bash
pip install -r requirements.txt
python train_model.py
streamlit run app.py
```

## Components
- CSV student dataset
- Data preprocessing
- K-Means clustering
- Random Forest classification
- Evaluation
- Streamlit interface

The included CSV is a synthetic/anonymized demonstration dataset and should not be represented as institutional student data.
